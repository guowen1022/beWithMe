- [7/10][research/embedding-collapse] **Investigate the nomic-embed-text short-input collapse bug** that surfaced in the recipe-replay generalization test (`tests/manual/test_recipe_generalization.py`). Verified by direct Ollama API hit (the collapse happens inside the model, not our code). For recipe lookup this is currently a *helpful* accident — same-shape questions hit the same recipe — but it's fragile and probabilistically wrong. We need to understand it before relying on it. Investigation plan: (1) read nomic-embed-text's tokenizer + pooling behavior; is it mean-pooling and the proper-noun tokens get drowned out when common-vocabulary "impact on Europe of" dominates? Files to touch when fixing: `infra/rag/embedding.py` (the embed_text call site), `workshop/research/recipes.py:record_after_success` (where the goal is embedded for storage), `workshop/research/recipe_store.py:lookup` (where the runtime goal is embedded for match).
